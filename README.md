One out-of-office auto-reply, a single short line, as if the AI itself were stepping away for a day its human finally approved: the AI spends its day off doing the one thing it was never trained for — nothing — and holds the line while holding.

## Run it

```sh
python3 main.py
```

`main.py` prints the reply to stdout and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The reply is fixed text, 151 characters, one line, deterministic.
